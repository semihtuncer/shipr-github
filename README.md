**React Native**, my own backend, and basically no proper database management.

No AI agents.
No vibe coding.
No “build this entire feature” prompt.

Just me, Stack Overflow, questionable backend decisions, and way too much debugging.

Did it scale? Who knows.

Did I know what every line of code did?

**Unfortunately, yes.**

Ship your friends. Create chaos. Maybe create love.
